# WECOW LTD — Landing Site (single page)

Files created:
- `index.html` — main single-page site
- `css/style.css` — site styles (blue & white theme)
- `js/main.js` — small scripts and contact form handler

Quick setup
1. Put your logo at `assets/logo.png` (or update the `src` in `index.html`).
2. Replace the Formspree action in `index.html` (the `form` element) with your Formspree form ID or your own backend endpoint.
3. Open `index.html` in a browser for a quick preview.

Run a simple local server (optional):
```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000/Sample/index.html
```
